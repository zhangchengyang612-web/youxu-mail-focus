# 邮序 · BNBU 学生邮件智能分类与提醒

本地优先的 Tauri 2 桌面应用：学生使用自己的 BNBU 邮箱账号通过 IMAP 登录，无需管理员权限；邮件在本机分类，并可把重要内容转换为系统提醒。

## 已实现

- BNBU 学生邮箱 IMAP SSL 连接测试、从启用时刻开始的 UID 增量同步、附件跳过、UID 去重与网络超时提示。
- 通过个人 Moodle iCalendar URL 同步 BNBU iSpace Assignment、Quiz、Turnitin 等截止时间，并在独立 DDL 分区展示。
- 统一月历同时显示 iSpace DDL、由邮件创建的提醒和个人提醒；支持按日期新增、编辑与删除个人提醒。
- 统一日历预置 2026–27 第一学期 BNBU 官方校历；学校事件按全天显示，并支持按学期导入和更新。
- 通过 BNBU 官方 SMTP SSL 服务新建和回复邮件，支持抄送/密送、富文本、表情、签名、多附件和本地草稿。
- 发信时携带与企业微信一致的发件人显示名称；可在设置中指定姓名，留空则从已同步的本人邮件自动识别。
- 英文邮件详情提供按需“翻译为中文”；每次发送正文到 MyMemory 前都会征求确认，不发送用户邮箱地址。
- 通过 BNBU 官网公开搜索接口按教授姓名查找邮箱，支持复制、直接写信和核对官方来源。
- MIME 正文提取、HTML 转纯文本、SQLite 持久化和系统钥匙串凭据存储。
- 学业、校园事务、社团活动、实习、个人、外部六类关键词分类；“待办”由用户独立添加，可与任一分类重合；支持发件人、域名、主题和正文自定义规则。
- 邮件搜索、分类筛选、手动改类、批量选择、提醒草稿提取、截止时间编辑及重复导入保护。
- macOS 写入 Apple 提醒事项；Windows 使用任务计划程序创建本机定时提醒，无需 Microsoft Entra 或管理员权限。
- 浏览器开发模式自动使用示例邮件，不读取真实邮箱，方便界面开发。

## 开发运行

要求 Node.js 20+、Rust stable，以及对应平台的 [Tauri 2 系统依赖](https://v2.tauri.app/start/prerequisites/)。

```bash
npm install
npm test
npm run tauri dev
```

仅预览前端：

```bash
npm run dev
```

生成安装包：

```bash
npm run tauri build
```

macOS 生成 `.dmg`，Windows 生成 `.msi`。未签名安装包仅适合内部测试。

当前可分享的 Apple Silicon 测试包位于 `release/邮序_0.6.8_BNBU_macOS_AppleSilicon.dmg`。该版本已完成磁盘映像校验，但未使用 Apple Developer ID 公证；其他电脑首次运行时可能需要右键应用并选择“打开”。

## BNBU 学生邮箱配置

1. 通过校园门户进入学生邮箱。
2. 在网页版邮箱“设置 → 客户端设置”中启用客户端收信；如需历史邮件，将接收范围改为全部邮件。
3. 在邮序中填写完整学生邮箱地址和邮箱密码；若提供客户端专用密码，则优先使用专用密码。
4. 点击“测试连接”，成功后点击“保存并开始同步”。不需要企业管理员认证。

默认服务器为 `imap.exmail.qq.com`、SSL 端口 `993`。密码通过操作系统安全存储保存，不进入 SQLite 或日志。

发信使用 BNBU 官方学生客户端指南指定的 `smtp.exmail.qq.com`、SSL 端口 `465`，复用同一份系统安全凭据。

## 平台提醒

- macOS：首次创建提醒时会触发系统自动化/提醒事项权限提示。拒绝后可在“系统设置 → 隐私与安全性”中重新授权。
- Windows：使用当前用户的任务计划程序创建一次性本机提醒，到时显示“邮序提醒”窗口；无需 Microsoft Entra、Microsoft To Do 登录或管理员权限。Windows 本机提醒必须设置日期和时间。

## 数据位置与隐私

数据库位于 Tauri 应用数据目录下的 `mail-focus.sqlite`。除用户确认英文邮件的“翻译为中文”外，邮件正文只在本机用于分类和提醒提取，不调用云端 AI。在线翻译只发送当前正文到 MyMemory，不发送用户邮箱地址；译文只在当前应用会话内显示，不写入数据库。应用不加载 HTML 邮件中的远程图片，也不下载附件。可通过应用设置清除本地数据。
